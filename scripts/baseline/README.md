# baseline —— 迁移基线快照（只读，不要当源码改）

`wxml/` 里是 **9 个页面的原生 WXML 冻结快照**，拷贝自原生工程
`../diancan-miniprogram/miniprogram/`（拷贝于 2026-09-14，与当时原生文件逐字节相同）。

## 为什么留着它

`scripts/verify-structure.mjs` 的判据是「基线里用到的 class，构建产物里一个都不能少」。
原生工程已废除，如果基线也跟着删掉，这个回归工具就会失效 —— 而它恰好是
迁移后防止「模板元素整体丢失」最有用的一道网。

所以基线被**固化进本工程**，与原生工程的存废解耦。

## 使用约定

- **不要修改这些 wxml**。它们是参照物，不是源码；改了就失去比对意义。
- 想临时跟别的目录比对，仍可显式传参：`node scripts/verify-structure.mjs <目录>`。
- 如果确实要在产物里**主动删掉**某个 class，走 `verify-structure.mjs` 里的
  `EXPECTED_MISSING` 白名单，并且必须写清原因（脚本会把它单独打印出来）。
  白名单只适用于「已经知道为什么」，不适用于「先让它变绿」。
- 基线是骨架，不是全部：`scripts/inject-style.mjs` 需要原生 `.wxss` 才能重跑
  （样式已整文件注入到各 `.vue`，日常不需要再跑）。真要重跑，得先把原生工程
  从归档里解出来。
